# MindEase — Sample Data and Test Cases

## 1. Purpose
This document describes example scenarios for evaluating the current MindEase web prototype. Results must be recorded after testing; no tests are considered passed in advance.

## 2. Sample Scenarios
- Scenario A: A student visits the website to explore well-being resources.
- Scenario B: A user navigates between the available sections.
- Scenario C: A user interacts with an available button or form.
- Scenario D: A user opens the website on a mobile-sized screen.
- Scenario E: A user refreshes the page or opens it again.

Use fictional information only. Do not enter real personal or sensitive health information.

## 4. How to Test
1. Open https://gouseiafatma.github.io/MindEase-App/
2. Run each test manually in a browser.
3. Record Pass or Fail in the actual result column, with notes about any problems.
4. Retest after any relevant fixes.

## 5. Limitations
These are manual test cases for a static web prototype. They do not establish that backend services, AI responses, authentication, data storage, or counsellor booking are available.
